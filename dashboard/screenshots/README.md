# InfraOps Dashboard Screenshots

This folder contains visual evidence of the InfraOps infrastructure monitoring and incident-analysis prototype.

## Power BI Monitoring Dashboard

**File:** `InfraOps-Dashboard.png`

The dashboard summarizes the sample incident dataset, including:

- Total incidents analyzed
- High-priority incident count
- Number of affected servers
- Incident priority scores
- Incident categories and recommended actions

## Data Scope

The dashboard uses locally generated sample incident data and rule-based PowerShell analysis. It is a prototype and does not currently display live Azure Monitor or Log Analytics data.
